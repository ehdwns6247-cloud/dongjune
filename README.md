# 단어의 고리

공무원 영어 단어 2,500개를 주제별 DAY 1~50으로 학습하는 모바일 대응 단어장입니다. 각 DAY는 50개이며, 어려운 단어는 현재 학습에서 다른 단어 3개 뒤에 뜻을 가리고 다시 나옵니다.

## 실행

`dist/index.html`을 브라우저로 여세요. 화면과 학습 자료가 HTML 한 파일 안에 포함되어 서버 없이 사용할 수 있습니다. 단어소리는 기기의 영어 음성을 사용하며, 기기 설정에 따라 인터넷이 필요할 수 있습니다. 사전 링크는 인터넷 연결이 필요합니다.

학습 기록은 기기와 브라우저에 저장됩니다. 파일 이동이나 브라우저 변경 전 앱의 **기록 내보내기**를 이용하세요. 개인 기록은 이 저장소에 올리지 않습니다.

## 수정할 파일

| 수정 내용 | 파일 |
| --- | --- |
| 학습 동작·화면 구성 | `src/app.js` |
| 색상·배치·모바일 화면 | `src/style.css` |
| 단어별 뜻·발음·연결 단서·장면 | `src/cards.json` |
| DAY 주제와 단어 배치 | `src/days.json` |
| 자료 안내 | `src/corpus-note.json` |
| HTML 기본 틀·발음 자료 라이선스 | `src/template.html` |

단어 입력이나 사진 인식 작업을 다시 실행할 필요 없이 필요한 파일만 수정합니다. 생성된 `dist/index.html`은 직접 편집하지 않습니다.

## HTML 만들기와 검사

Python 3와 Node.js를 사용합니다. 별도 패키지 설치는 필요 없습니다.

```sh
python scripts/build.py
node tests/app.test.cjs
```

생성기는 2,500개 고유 ID, DAY별 50개 배치, 필수 설명 필드를 확인합니다. 기능 검사는 모든 카드 표시, DAY 선택, 검색, 반복 학습 등을 검사합니다. 언어 설명의 정확성을 자동으로 보증하는 검사는 아닙니다.

## 버전 관리

화면 수정과 단어 내용 수정을 작은 단위로 기록합니다. 수정 후 HTML 생성과 관련 검사를 실행하고 변경 이유를 커밋에 남깁니다. `dist/index.html`도 함께 저장해 특정 버전의 실행 파일을 바로 받을 수 있습니다.

원본 사진, 임시 OCR 도구와 설치 파일, 개인 학습 기록은 포함하지 않습니다. 책의 색인 단어 목록을 바탕으로 학습 설명·장면·짧은 표현을 별도로 작성했습니다. 발음 자료는 [ipa-dict](https://github.com/open-dict-data/ipa-dict)를 참고했으며 MIT 라이선스 고지는 HTML에 포함되어 있습니다. 사진 판독 및 언어 설명은 추가 검수·수정할 수 있습니다.
